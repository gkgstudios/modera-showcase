## Modera Style

The four images in `app/` are unchanged product screenshots selected from the assets used on [Modera's public website](https://www.modera.fyi/):

| File | Screen |
| :--- | :--- |
| `wardrobe.png` | Wardrobe catalog |
| `outfits.png` | Outfit discovery |
| `suggestions.png` | Wardrobe-aware shopping suggestions |
| `history.png` | Saved outfit history |

They illustrate the interface and example garment imagery; they are not evidence of adoption, styling accuracy, or individual user outcomes. The selected captures contain no account details or personal photos.

## Modera for Muse

`muse/panel-view.jpg` and `muse/assembled-view.jpg` are unchanged screenshots captured in Muse from a fictional sample wardrobe demonstration. Modera selected the combinations. Muse generated the garment appearances.

The screenshots show the same two sample outfits in different views. They contain no personal wardrobe, likeness, source photos, or Gmail content. Captions in the showcase explicitly identify the AI-generated sample imagery.

## Banner

`modera-banner.svg` is a vector graphic created for this showcase. It contains only text and decorative shapes; it has no scripts, embedded resources, or external dependencies.
